Exercise 1:
void example1(int n) {
    for (int i = 0; i < n; i++) {
        System.out.println(i);
    }
}
Solution:
Only one loop
The loop runs n times depending on the value of n
The complexity is linear which is equal O(n).
Exercise2:
void example2(int n) {
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            System.out.println(i + " " + j);
        }
    }
}

Two loops
the outer loop runs n time
for every iteration of the outer loop,
the inner loop also runs 
complexity outer loop = O(n)
complexity inner loop = O(n)
total complexity = O(n)*O(n) =O(n^2)

Exercise 3:
void example3(int n) {
    for (int i = 1; i < n; i *= 2) {
        System.out.println(i);
    }
}
Complexity is O(log2)

Exercise 4:
void example4(int n) {
    for (int i = 0; i < n; i++) {
        for (int j = i; j < n; j++) {
            System.out.println(i + " " + j);
        }
    }
}

complexity O(n^2) this is because for every iteration of the outer loop the inner loop must run n time.
